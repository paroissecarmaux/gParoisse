Sauvegarde des données

Les données sont stockées uniquement dans ce navigateur (aucun serveur, aucune synchronisation). Une exportation JSON régulière est indispensable : c'est le seul moyen de les récupérer en cas de problème.

Données

L'export JSON sauvegarde l'intégralité des données (demandes, personnes, annonces). Faites-en une régulièrement : le stockage du navigateur n'est pas un système de sauvegarde sécurisé.

Importation

À partir d'une sauvegarde JSON complète : fusionner avec les données actuelles, ou tout remplacer.

Export / import CSV par base

Chaque base peut être exportée et réimportée séparément au format CSV (tableur). La colonne « ID » permet de mettre à jour un enregistrement existant lors d'une réimportation plutôt que de le dupliquer.
